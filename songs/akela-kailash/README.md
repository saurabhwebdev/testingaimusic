# Akela Kailash (अकेला कैलाश)
A sad, melodic Shiva song: Mahadev grieving Sati, waiting for her return as Parvati.

| File | What |
|---|---|
| `akela-kailash.mp4` | Final lyric video (1080p, with Hindi + Roman captions) |
| `thumbnail.jpg` | YouTube thumbnail (1280×720) |
| `youtube.md` | Title, description, tags and upload settings |
| `akela-kailash.hi.srt` / `.hi-Latn.srt` | Subtitle files for YouTube |
| `akela-kailash.mp3` | Song audio (Suno) |
| `lyrics.md` | Original lyrics |
| `prompt.md` | Suno style prompt |
| `image-prompts.md` | Image prompts |
| `images/` | The 7 scene images used in the video |
| `video-source/` | ffmpeg scripts used to build the video |
